# Learned gate for the pass selector (does ZX pay?)

`[F]` Generated by value/zx_classifier.py. No new compilation. Labels from value/selector_ledger_circuits.csv (A, B1, B1x, B2), value/family_C_selector.csv (C) and value/usecase.csv (U). B1x is count-only and unchecked. Features from the input QASM in bench/ only. Seed 20261009.

## Method

- Label `pays` = round(hqc_P2, 6) < round(hqc_P0, 6) at 1000 shots. Ties count as does not pay.

- Features (input circuit, no compilation): n_qubits, n_gates, n_cx, n_t, n_cont, n_h, n_ccx, depth, frac_cont, t_density, cx_density, zx_spiders. n_t counts T, Tdg and rotations at odd multiples of pi/4. n_cont counts rotations whose angle is not a multiple of pi/4. zx_spiders is the vertex count of the unsimplified PyZX graph. The family label is not a feature. Counts enter as log1p.

- Models: logistic regression (standardised, class_weight balanced, C = 1) and gradient-boosted trees (100 trees, depth 2, learning rate 0.1). gbt_reg is a gradient-boosted regressor on rel_saving = (hqc_P0 - hqc_P2)/hqc_P0 that predicts pays when the predicted saving is positive. No hyperparameter search.

- LOFO: train on all other families, predict the held-out family. GCV: GroupKFold(5, shuffle, seed 20261009) over 38 construction groups (A: model and n. B1, B1x, C and U share groups by construction name, so vbe_adder, tof, barenco_tof, gf2_pow_mult, hwb and grover never straddle a fold. B2: qubit count).

- Regret = sum of HQC(choice) - min(hqc_P0, hqc_P2) over the circuits. One compilation per circuit.

- Gated policy: always compile P0, compile P2 only on a predicted pays, keep the cheaper. regret_gated is its regret (false negatives only). skipped = number of P2 compilations it skips.

- B1x shares constructions (tof, barenco_tof, gf2_pow_mult) with B1, so its LOFO split is not construction-disjoint. The GCV split is.

- Balanced accuracy is the mean recall over the classes present. B2 has no circuit where P2 pays and U has no circuit where it does not, so on those families it reduces to plain accuracy.

- rule_cont is a fixed hand rule with no fitting: predict pays exactly when the input has no continuous-angle rotation (n_cont = 0). It is listed to show how much of any gain a single feature explains.

- always_P2 under the gated policy is the existing two-compilation selector (regret 0, nothing skipped).
