## Instances

- `[F]` Grover search (arXiv:quant-ph/9605043) with one marked item among N = 2^d, k = floor(pi/4 sqrt(N)) iterations. Oracle and diffusion each use one C^(d-1)Z, built as H C^(d-1)X H with the C^m X of Barenco et al. (arXiv:quant-ph/9503016, Lemma 7.2): 4(m-2) Toffolis and m-2 ancillas restored in any state. Each Toffoli is the 7-T, 6-CX network of Nielsen and Chuang (2000), Fig. 4.9.
- `[F]` HQC uses `compile.hqc` at 1000 shots with every qubit measured, ancillas included.
- `[O]` The Barenco construction is not T-optimal. Relative-phase Toffolis would lower the written T-count. The instances are kept as written in the cited sources.
