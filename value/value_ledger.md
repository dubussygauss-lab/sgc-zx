## Sources and definitions

- `[F]` HQC = 5 + C (N_1q + 10 N_2q + 5 N_spam)/5000 (`pipelines/compile.py` `hqc()`), N_1q = PhasedX, N_2q = ZZPhase + ZZMax, N_spam = n_qubits + Measure + Reset. Here every qubit is measured once, so N_spam = 2 n_qubits (checked against the stored `hqc` column for every row). C = 1000 shots.
- `[F]` Shots affordable at a fixed budget of 10,000 HQC: floor((B - 5) 5000 / (N_1q + 10 N_2q + 5 N_spam)).
- `[F]` Fit slope a = 1.1801e-03 per two-qubit gate, read from `results/proxy_h22e_fits.log` line 77, Family B1 section: `a n_2q only                                        a = 1.1801e-03 +/- 2.3e-05 ; resid sd 7.97e-03 ; R^2 0.9675`.
- `[F]` p2 = 0.00129, H2-2E emulator default two-qubit fault probability, `noise/h2_params.py` `H2_2E_EMULATOR['p2']`.
- `[O]` Fidelity columns are model predictions, not measurements: F_P2/F_P0 = exp(a dN_2q) with dN_2q = N_2q(P0) - N_2q(P2), and the same with p2 in place of a. The slope a comes from a local density-matrix proxy fit of -ln F_H on 35 B1 rows. It assumes all fidelity loss scales with the two-qubit count and ignores the single-qubit and depth differences between P0 and P2. The fit rows span n_2q <= 189 (`results/family_B1_proxy_h22e.csv`). Rows with `fit_extrapolated = True` lie outside that range and their fidelity numbers are extrapolations. F_P0_model_fit_a = exp(-a N_2q(P0)) is shown so the reader sees when the absolute fidelity is already negligible.
- `[F]` One |T> magic state is consumed per T gate: Litinski, "A Game of Surface Codes: Large-Scale Quantum Computing with Lattice Surgery", Quantum 3, 128 (2019), doi:10.22331/q-2019-03-05-128, arXiv:1808.02892. Section 2 of the arXiv version: "Clifford+T circuits are a sequence of pi/8 rotations, each requiring the consumption of a magic state". Magic-state counts below are therefore equal to T-counts.
- `[F]` T_zx_P2 is the PyZX T-count after the ZX stage of P2 (`t_count_zx` in the B1/B1x CSVs, `t_count_after_zx` in B2). `n_non_cliffordT_zx` is 0 on every B1 and B1x P2 row, so no non-Clifford+T phase is left uncounted.
- `[F]` Certified floor = `lde_floor` in `results/certificates.csv` (all rows `sound = True`, 0 criterion violations). Incompressible fraction of the remaining T-count = floor / T_zx_P2. The script asserts that `t_written` and `t_zx_P2` in the certificate file equal the counts CSVs.
- `[F]` B1x rows have `status = ok-unchecked`: counts only, no equivalence check. B1 and B1x are reported separately and never merged.
- `[O]` Conversion of magic-state counts to wall-clock time, qubit overhead or cost on Helios or H2 needs device-specific factory and logical-cycle figures. No Quantinuum source found in this pass states such a conversion, so none is made.
- `[F]` Context only, not used in any number above: Dasu et al. (Quantinuum), "Breaking even with magic: demonstration of a high-fidelity logical non-Clifford gate", arXiv:2506.14688 (https://arxiv.org/abs/2506.14688), report on H1-1 a logical magic state with experimental infidelity 7(+3/-1) x 10^-5 and a logical CH gate with infidelity <= 2.3(9) x 10^-4. The abstract gives no per-magic-state time or HQC cost.
