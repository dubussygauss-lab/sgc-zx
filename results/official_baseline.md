# Official pytket-quantinuum default pass against the reproduced P0

Generated by `pipelines/official_baseline.py report` from `results/official_baseline.csv` and `results/family_{A,B1,B1x,B2}_counts.csv`. No number is typed by hand.

`[F]` Versions: pytket 2.18.4, pytket-quantinuum 0.59.3. Backend `QuantinuumBackend(device_name="H2-1", api_handler=QuantinuumAPIOffline())`, built from the device list bundled in the package. No network call, no job, no HQC.

`[F]` P0off = `backend.get_compiled_circuit(circ, optimisation_level=2)`. P2off = `compile.zx_teleport_reduce` then `backend.default_compilation_pass(optimisation_level=2)`. Ours = the P0 and P2 rows of `results/family_*_counts.csv` (reproduced pass, `compile.quantinuum_default_pass(2)`). HQC at 1000 shots with `compile.hqc(comp, n_measure=n_qubits)`. n_2q = ZZPhase + ZZMax, n_1q = PhasedX.

## Pass structure

`[F]` Official sequence: DecomposeBoxes, CustomPass, FullPeepholeOptimise, NormaliseTK2, DecomposeTK2, AutoRebase, RemoveRedundancies, AutoSquash, RemoveRedundancies, RemovePhaseOps, FlattenRelabelRegistersPass.

`[F]` Reproduced sequence: DecomposeBoxes, CustomPass, FullPeepholeOptimise, NormaliseTK2, DecomposeTK2, AutoRebase, RemoveRedundancies, AutoSquash, RemoveRedundancies, RemovePhaseOps, FlattenRelabelRegistersPass. Same names in the same order: True.

`[F]` Serialised parameter differences:

- step 5 AutoRebase `basis_allowed`: official only ['ClExpr', 'CopyBits', 'ExplicitModifier', 'ExplicitPredicate', 'JobShotNum', 'MultiBit', 'RNGBound', 'RNGIndex', 'RNGNum', 'RNGSeed', 'RangePredicate', 'SetBits', 'WASM'], reproduced only []

`[F]` The extra AutoRebase basis entries of the official pass are classical and control-flow op types. AutoRebase leaves basis types untouched and no benchmark input contains any of them, so they cannot change a count here.
